賽銭（お賽銭）の作法と参拝方法

English Version

神社仏閣で神様・仏様への敬意を示すための、正しい参拝手順と賽銭の入れ方について解説します。

🪙 賽銭の意味と入れ方

賽銭とは

賽銭は、神様や仏様との**ご縁を結ぶ**ため、あるいは日頃の感謝や願い事を込めて捧げる供え物です。金額に決まりはありません。

投げ入れ方

賽銭は、乱暴に投げ入れるのではなく、丁寧に賽銭箱に入れます。特に音を立てて入れる（例：五円玉を入れる）と縁起が良いとされる風習もありますが、基本は静かに捧げます。

🙏 神社での参拝の基本

神社では、一般的に以下の手順で参拝します。

  1. 賽銭を入れる。
  2. **鈴を鳴らす**（神様を呼ぶため）。
  3. **二礼**（二回お辞儀をする）。
  4. **二拍手**（二回手を叩く）。
  5. **一礼**（もう一度お辞儀をする）。

お寺での参拝

お寺では、手を合わせて静かに祈るのが基本です。神社のような拍手はしません。
